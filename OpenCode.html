1為什麼用 OpenCode + 本地模型設計數學教案？

OpenCode 是一個能在你電腦上運行、與本地大型語言模型（LLM）對話的開發助手。把它用來設計「108 課綱國小數學」單元教案，好處有三：

  • 完全離線、不外漏：教案內容常含學校、班級甚至學生資料，使用本地模型可避免資料上傳到公有雲，符合校園資安與個人資料保護。
  • 不用付 API 費：本地模型（如 Qwen2.5、Llama-3）下載一次後可重複使用，長期成本為零。
  • 可反覆修改提示詞：OpenCode 能幫你草擬教學目標、活動設計、評量題目，你再依課堂實際狀況人工調整，AI 當「助教」，你當「主教」。
重點提醒：AI 生成的教案只能作為參考草稿，最終的教學目標與評量標準仍須由教師依 108 課綱指導要點與學生實際情況確認。

2108 課綱國小數學科快速複習

台灣十二年國民基本教育課程綱要（108 課綱）國小數學（國小 1–6 年級）以「核心素養」為核心，內容領域分為四大類：

領域數與量（N）

數的意義與運算、量、比例、分數、小數、百分數、整數與分數的四則運算等。

領域幾何（G）

平面圖形與立體圖形、位置與對稱、長度、面積、體積、角、圓等。

領域代數（A）

模式與關係、代數符號、函數初探（高年級）、不等式等。

領域機率與統計（S）

資料收集與整理、圖表、機率直覺、簡單機率計算等。

123456 國小六年級皆需涵蓋上述領域，難度依年級遞進。

3一份完整國小數學教案應包含什麼？

OpenCode 可協助撰寫以下各區塊，建議新手先熟悉結構，再請 AI 逐區塊生成：

區塊內容建議
教案名稱年級、單元名稱、節次（例如：五年級 第 11 章 第 3 節）
教學目標依 108 課綱學習表現撰寫，包含「知識與技能」、「過程與能力」、「核心素養」三面向。
前置知識學生已經會的內容，作為新課銜接點。
教學資源教具、投影片、工作單、操作材料（如分數圓片、長方體模型）。
教學流程導入（5–8 min）→ 發展（25–30 min）→ 總結（5 min）→ 評量（5 min）。
形成性評量課中提問、操作觀察、工作單，即時回饋。
總結性評量單元結束的測驗、檔案評量，判斷學習目標達成程度。
教學反思上課後記錄什麼有效、什麼需修改，做為下次備課參考。

4環境準備：安裝 Node.js

OpenCode 需要在 Node.js 環境中運行。如果你的電腦還沒裝 Node.js，請先安裝：

1

前往 https://nodejs.org 下載 LTS 版本（穩定版，推薦新手）。

2

依畫面指示一路「下一步」完成安裝（Windows 用戶記得勾選「Add to PATH」）。

3

安裝完成後，打開「命令提示字元」（Windows）或「終端機」（macOS / Linux），輸入：

node -v
npm -v

若出現版本號碼（例如 v20.11.0、10.2.4），代表 Node.js 安裝成功。

跑通標誌：終端機能正常顯示 node 與 npm 版本。

5安裝 OpenCode（本地 AI 編程助手）

OpenCode 是讓你在本地端與 AI 對話、協助撰寫教案與程式碼的工具。安裝方式請依 OpenCode 官方文件為準；以下以常見的 npm 全域安裝為例：

# 在終端機輸入
npm install -g opencode

安裝完成後，輸入以下指令確認：

opencode --version

若顯示版本號，安裝成功。接著啟動 OpenCode：

opencode
注意：若終端機顯示「opencode：找不到指令」，請重新開啟終端機，或參考 OpenCode 官方安裝頁面確認最新指令（套件名稱可能會隨版本調整）。

6接上本地模型（以 Ollama 為例，完全離線運行）

OpenCode 本身不內建模型，需要連接一個「本地模型供應商」。這裡以 Ollama 為例，它是目前在個人電腦上運行本地 LLM 最流輕量的工具之一，且支援繁體中文較好的模型（如 Qwen2.5）。

步驟 A：安裝 Ollama

  1. 前往 https://ollama.com 下載並安裝 Ollama（Windows / macOS / Linux 皆有）。
  2. 安裝完成後，終端機輸入 ollama --version 確認安裝成功。

步驟 B：下載適合教案設計的模型

建議新手先下載 Qwen2.5:7b-instruct（中文能力強、7B 參數大筆電也能跑）：

ollama pull qwen2.5:7b-instruct

記憶體較大的電腦（16GB 以上）也可嘗試 qwen2.5:14b-instruct，效果更佳。

步驟 C：在 OpenCode 中連接本地模型

  1. 啟動 Ollama（通常背景已自動運行，預設網址為 http://localhost:11434）。
  2. 在 OpenCode 的設定中，選擇使用「本地模型 / Ollama」，並指向 http://localhost:11434。
  3. 選擇剛才下載的模型名稱 qwen2.5:7b-instruct。
  4. 輸入一句測試話語，例如：「你好，請用繁體中文自我介紹。」若模型回覆，即代表跑通。
跑通標誌：你在 OpenCode 輸入「你好」，本地模型能以繁體中文回覆，且不需要連接網路。

7實作範例：五年級《分數的乘法》單元教案

我們以國小五年級「數與量」領域《分數的乘法》為例，示範如何請 OpenCode 生成教案草稿，以及最終教案長什麼樣子。

7.1 輸入的提示詞（Prompt）

在 OpenCode 對話框貼入以下提示詞（可直接複製，見附錄完整版本）：

請你扮演國小數學教師，依據台灣 108 課綱，設計一份五年級「分數的乘法」單元教案（一節 40 分鐘）。
請包含：教學目標（三面向）、前置知識、教學資源、教學流程（導入/發展/總結/評量）、形成性評量題目兩題、教學反思建議。
語言：繁體中文。

7.2 OpenCode 與本地模型回傳的教案草稿（片段）

流程時間教與學活動重點
導入5 分鐘出示「1/2 塊餅乾」與「1/3 塊餅乾」圖片，提問：「如果要把 1/2 塊餅乾平均分成 3 份，每份是多少？」引出分數乘法的情境。
發展25 分鐘使用分數圓片操作：展示 (1/2)×(1/3) 的面積模型，引導學生發現「分子相乘、分母相乘」的規則，練習 2–3 題計算，並討論為何結果會變小。
總結5 分鐘全班口頭回饋：分數乘法的算式與意義，老師板書重點公式。
評量5 分鐘工作單兩題：(2/3)×(3/4) 計算；一題應用題（披薩分享），形成性評量。

7.3 教師後續工作（人工修改重點）

  • 確認教學目標是否對應你學校所用教科書版本（康軒、南一、翰林等）。
  • 依班級學生實際程度調整題目難度與時間分配。
  • 將生成的教案匯出為 Word / PDF，上傳至校園備課平台。

常見問題 Q&A

  • Q：電腦沒有網路可以用嗎？
    A：可以。Node.js 與 OpenCode 需首次安裝時連網；本地模型下載後，後續完全離線運行。
  • Q：筆記型電腦夠不夠跑本地模型？
    A：8GB 記憶體可跑較小的模型（如 3B），建議 16GB 以上搭配 7B 模型，體驗較佳。
  • Q：生成的教案有錯誤怎麼辦？
    A：AI 可能會 hallucinate（編造）指標編號，務必對照 108 課綱官方指導要點人工校對。
  • Q：可以換其他模型嗎？
    A：可以，Ollama 支援多種模型（Llama-3、Gemma 等），在 OpenCode 設定中切換即可。
隱私提醒：使用本地模型時，提示詞與教案內容不會上傳到雲端，適合處理含有學校或班級資訊的教學材料。

請你扮演經驗豐富的國小數學教師，熟悉台灣 108 課綱數學領域。

請設計一份國小 [年級] 年級「[單元名稱]」單元教案，預計 [節數] 節（每節 40 分鐘）。

請包含以下區塊：
1. 教學名稱與適用年級
2. 對應 108 課綱領域與學習表現（如有指標編號請務必準確）
3. 教學目標（知識與技能 / 過程與能力 / 核心素養）
4. 學生前置知識
5. 教學資源與教具建議
6. 詳細教學流程：導入 / 發展 / 總結 / 評量（含每項預估分鐘數）
7. 形成性評量題目（2–3 題，含簡短解答）
8. 總結性評量建議
9. 教學反思重點

請使用繁體中文，語氣親切、實用，適合新手教師直接參考與修改。
